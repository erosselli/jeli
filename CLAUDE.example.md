# Task tracking

I track my work in jeli (`~/jeli`). At the start of any unit of work (planning or implementing a ticket/PR, self-review, reviewing a PR or PR stack, an investigation/RCA, a release), invoke the `tasks` skill and log it before doing anything else, alongside whatever skill does the work. Close or update the task when the work hits an end point the skill defines. One-off questions don't get a task; if unsure, ask me.
